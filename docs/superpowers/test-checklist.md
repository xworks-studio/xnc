# XNC v2 产品测试清单

> 使用方法：逐项操作，每项在三个维度打分（✅ 通过 / ⚠️ 需改进 / ❌ 不通过），并在备注列写具体问题。完成后把整份文档给 AI，我们按优先级修复。

**维度说明**：
- **易用性**：直觉性、错误提示质量、操作效率、信息是否充分
- **美观**：视觉整洁度、布局合理性、反馈清晰度（CLI 看输出格式，Web 看整体设计）
- **性能**：响应速度、大数据表现、资源占用感受
