## 阶段 1：TB16G7 实验（E1–E6，全部经 xnc，零产品代码改动）

**工具准备**：新建诊断工具 tools/dxgiprobe（~200 行，复用 git 历史中的 comPtr 基建）：打印 DuplicateOutput/AcquireNextFrame 时间线、帧计数、黑帧检测（全零像素统计）、首帧计时、光标-only 帧频率，支持 --dump 输出 .bmp/.h264 供 ffmpeg 验证。构建 dxgiprobe.exe 与 screendiag pipeclient。

**实验矩阵**：
- A 基线：xnc 确认节点在线、whoami（验证 SYSTEM/Session0 上下文）、qwinsta 会话拓扑、GPU 型号（Win32_VideoController，判断 NVIDIA RDP 黑帧风险）、screen --snapshot 取当前画面、xgc2/3/4 残留清点。
- E1 console+用户令牌：schtasks 以当前用户交互态运行 dxgiprobe → 复现或排除当年 0x887A0001。
- E2 console+SYSTEM-in-session：schtasks /RU SYSTEM /IT 运行 probe（目标形态验证）。
- E3 E2 状态下触发 UAC（Start-Process -Verb RunAs）：记录 AccessLost/黑帧/可见，决定安全桌面是否需要 GDI 备援切换。
- E4 RDP 会话：从本机 `xnc rdp LABS-TB16G7` 连入后在 RDP 会话内跑 probe，验证黑帧缺陷。
- E5 静止桌面首帧计时（含 duplication 重建后的首帧）。
- E6 光标-only 帧频率统计（光标合成层的重编码预算）。

**产出**：能力矩阵回填 + 架构决策记录；实验产物（计划任务、探针文件、RDP 会话）清理，删除前列清单确认。

## 阶段 2：实施（每步编译+测试全绿，顺序执行）

1. **协议元数据显式化**（先落地先止血）：SCREEN_BEGIN 扩展携带 codec/dims/state + WS 二进制帧 1 字节子头（key/delta）+ 帧上限统一 8MiB 常量进 proto（server/agent/CLI 三处引用同一常量）+ web/CLI 解码端同步（消灭三处 NALU 嗅探）。
2. **DXGI capturer**（实现 Capturer 接口）：首帧强制获取 + 超时有界重试（3 次）后降级 GDI；WAIT_TIMEOUT=静默跳过；光标-only 帧合成路径；CopyResource→staging→Map→立即 ReleaseFrame 纪律；DXGI_MODE_ROTATION 处理；ACCESS_LOST→退避重建状态机（观众收 reconnecting 状态）。
3. **GDI 备援恢复**：非 console 会话确定性走 GDI（规则不做黑帧探测）；安全桌面 SYSTEM+SetThreadDesktop(winlogon)+BitBlt 低帧率备援；GDI 行序黄金字节测试锁死。
4. **光标合成层**：三种指针格式（monochrome XOR/color/color-masked）归一 BGRA 叠加，黄金测试。
5. **编码层修正**：PTS 用 QPC 采集墙钟（废弃 30fps 假设）；时间基 GOP（>2s 强制 IDR）；fps 节流覆盖光标帧；NALU 手术收窄为"IDR 前必有 SPS/PPS + 4 字节起始码"。
6. **pixel 模块收拢**：scaleBGRA+bgraToNV12 单一实现 + 四象限/F 图案黄金测试。
7. **启动器**：TokenSessionId SYSTEM-in-session 变体（DuplicateTokenEx→SetTokenInformation→CreateProcessAsUser，依赖 E2 结论）。
8. **WGC 退役**：移除 WGCCapturer，Capturer/frameEncoder 接口保留。
9. **可观测性**：XNC_DUMP_H264 落盘开关（ffplay 直接验证=分界线工具）；SCREEN_STATE 周期计数器（captured/encoded/dropped/encodeMs/kbps/backend）；浏览器解码错误 SCREEN_FEEDBACK 回传。

## 风险与回退
- E3 证伪（SYSTEM DXGI 看不到安全桌面）→ 设计内已有 GDI 备援兜底，不阻塞。
- E1 显示 console 用户态 DXGI 仍失败 → 对照 WebRTC screen_capturer_win_directx.cc 排查调用上下文；仍失败则 GDI 主路径 + 状态帧明示。
- 全屏独占 ACCESS_LOST 风暴 → 指数退避兜底。
- 每步独立可回滚；任意环节故障用 XNC_DUMP_H264+ffplay 二分定位。
